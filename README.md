# BARBER HOUSE — Telegram Mini App + Render + Neon

## Architecture
- Telegram bot: grammY, webhook через тот же Render Web Service.
- Mini App/API: Node 22 HTTP server, hosted on Render.
- Database: Neon PostgreSQL.
- The bot and Mini App use the same booking functions and database.

## Deploy
1. Create a Neon PostgreSQL project and copy its pooled `DATABASE_URL`.
2. Create a Render Web Service from this repository. `render.yaml` is included.
3. Set `BOT_TOKEN`, `DATABASE_URL`, and `TZ_NAME` in Render. `WEBHOOK_SECRET` is generated by the included Blueprint. `WEB_APP_URL` is the HTTPS URL of the Render service.
4. Deploy. Open `/health` to verify the web service.
5. The bot and Mini App server start together. Render automatically provides the public URL, which is used for the Telegram webhook; Neon schema/seed data is created automatically on first start.
6. In BotFather, set the bot menu button if desired. The bot itself also shows an inline `📱 Открыть приложение` button when `WEB_APP_URL` is configured.

## Important
Rotate the Telegram bot token from the uploaded archive before deployment: it was present in the archive and must be treated as compromised.

The Mini App validates Telegram `initData` on the server before accessing user bookings or creating/canceling bookings.
